# Syntax-Practice

1.) ArraySlicing.go - Demonstrates the basic usage of Array and Slicing in Go</br>
2.) LettersExtr.go - Demonstrates the basic usage of maps in Go</br>
3.) Classification.go - Demonstrates getting input from the user then storing it to a map</br>
4.) JoinArr.go - Demonstrates combining two different array datas in to a single map</br>
5.) CombinedStructs.go - Demonstrates combining two different Structs into a single Struct</br>
6.) EmbdStructs.go - Demonstrates the basics of Embedding a Struct</br>
7.) Comp.go - Demonstrates a simple company hiring system using Structs and Methods</br>
8.) Store.go - A simple in-memory store simulation that can update and create a product</br>
9.) Admn.go - Demonstrates a simple role based powers using Structs and Methods</br>
10.) CompV2.go - Demonstrates deleting a value(firing an employee) using Structs and Methods</br> 
11.) Ship.go - Demonstrates a simple ship firing behavior using Struct & Interface</br>
12.) ErrHandling.go - Demonstrates a simple custom error handling</br>
13.) DepositErr.go - Demonstrates a simple error handling for a deposit value</br>
14.) Waitlist.go - Demonstrates a basic waitlist system using struct and interface</br>
